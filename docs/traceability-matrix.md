- Hosted health, strict index readiness, SQLite listing, and deep MCP discovery pass on runtime `071dfb8`. The latest hosted preflight passed both privacy refusals, then reached OpenRouter and received HTTP 429 from Qwen; the public API returned 503 with no resolved model or answer. That smoke output does not include a failure-scope field. The local `.env` key's read-only counter was exhausted, but Render key identity/quota is not independently confirmed. See [`evidence/hosted-pto-smoke.md`](../evidence/hosted-pto-smoke.md).
- Historical local remote-work and PTO responses resolved to specific free models for those requests only. The current hosted model has not completed an answer; rerun when quota is available and record the actual resolved model only from a successful `llm_refinement` trace.
- The recorded presentation, GitHub grader access, and course-dashboard submission are not artifacts that can be verified from this local checkout.
