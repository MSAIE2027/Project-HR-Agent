## Evidence quality notes

- The local full golden-set run reports deterministic rubric-based proxies; groundedness is not an independent semantic entailment judgment.
- The retrieval route and ablation queries are hand-labeled and small. They support the documented configuration choice for this corpus, not a universal optimum.
- Hosted health on `6ce0da8` reports a ready Hugging Face MiniLM index with 182 SQLite chunks and eight stdio tools; this is configuration and discovery evidence, not proof of a successful model answer.
- Historical local remote-work and PTO responses resolved to specific free models for those requests only. The latest hosted preflight returned 503 after four model attempts and did not resolve a model. No current hosted model is verified; see [`evidence/hosted-pto-smoke.md`](../evidence/hosted-pto-smoke.md).
- The recorded presentation, GitHub grader access, and course-dashboard submission are not artifacts that can be verified from this local checkout.
