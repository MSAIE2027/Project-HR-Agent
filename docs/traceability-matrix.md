## Evidence quality notes

- The local full golden-set run reports deterministic rubric-based proxies; groundedness is not an independent semantic entailment judgment.
- The retrieval route and ablation queries are hand-labeled and small. They support the documented configuration choice for this corpus, not a universal optimum.
- Hosted deep health on `1130dde` reports `huggingface_dense_cosine`-compatible Hugging Face MiniLM configuration and a ready 182-chunk SQLite index; this is configuration evidence, not proof that a hosted query completed dense retrieval.
- Historical local remote-work and PTO responses resolved to `poolside/laguna-s-2.1:free` and `inclusionai/ling-3.0-flash-fin:free` for those requests only. After the OpenRouter key replacement, two hosted E1002 PTO requests reached all four MCP tools and returned 503; their traces marked all routes unavailable without exposing per-route codes. A current local E1002 request returned 503 after all four MCP tools; each model route returned HTTP 429. No current resolved model is verified, and the provider-side cause is undetermined. See [`evidence/hosted-pto-smoke.md`](../evidence/hosted-pto-smoke.md).
- The recorded presentation, GitHub grader access, and course-dashboard submission are not artifacts that can be verified from this local checkout.
