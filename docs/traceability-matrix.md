## Evidence quality notes

- The local full golden-set run reports deterministic rubric-based proxies; groundedness is not an independent semantic entailment judgment.
- The retrieval route and ablation queries are hand-labeled and small. They support the documented configuration choice for this corpus, not a universal optimum.
- Hosted health, strict index readiness, SQLite listing, and deep MCP discovery passed on runtime `703a180`. A prior smoke passed privacy refusals plus cited remote-work and PTO confirmation-gate answers, with OpenRouter quota handoff to OpenCode `space-bunny-free`; a separate read-only remote-work request used the bounded SQLite template. These historical observations do not verify the latest saved key. The template is not live generation and cannot bypass confirmation. See [`evidence/hosted-pto-smoke.md`](../evidence/hosted-pto-smoke.md).
- The post-deploy current-key check remains open. Record the resolved model only from a fresh synthetic response with completed `llm_refinement`; require both cited PTO and remote-work answers and confirm the PTO gate remains active without invoking a mock action.
- The recorded presentation, GitHub grader access, and course-dashboard submission are not artifacts that can be verified from this local checkout.
